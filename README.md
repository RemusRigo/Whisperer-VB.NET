# Whisperer
Whisperer: a Windows customization/tweak tool



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Windows AI:
  * Disable Copilot, Recall, Cortana
  * Disable Bing/Web Search, search suggestions, search access to Location and Store
  * Remove AI features from Notepad and Paint
* TaskBar:
  * SearchBox settings
  * Show/hide Widgets (current user), disable Widgets (all users)
* Theme: Light/Dark theme for Apps and System
* Shows the execution time of each action
* Checks if it runs with elevated privileges (run as admin)
* Planned: Regional Settings, Start Menu, Hyper-V, Microsoft Edge
